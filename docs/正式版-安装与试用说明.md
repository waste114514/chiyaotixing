## 2. 从测试版换到正式版（会清数据）

正式版签名和测试版不同，Android 不允许覆盖安装。步骤：

1. **先导出备份**：打开现在的测试版 → 设置 → 数据 → 导出备份 → 存到文件管理/下载。
2. 记下几个关键设置：一天几顿、字号、锁屏卡片是否开着。
3. 卸载测试版：长按图标 → 卸载（或在设置 → 应用 → 药点 → 卸载）。
4. 安装 `药点-1.0.0-release.apk`。
5. 打开 App，允许通知权限。
6. 设置 → 数据 → 从备份恢复 → 选刚才导出的 JSON → 确认恢复。
7. 重新开启锁屏卡片：设置 → 提醒状态 → 锁屏卡片 → 设置 → 打开「锁屏吃药卡片」。
   - 如果开关是灰的：点「打开应用设置」，允许「受限制的设置」，再回来开。
8. 在 vivo 上建议再检查：
   - i管家 → 应用管理 → 权限管理 → 自启动 → 药点：允许（保证重启后通知能恢复）
   - i管家 → 应用管理 → 权限管理 → 锁屏显示 → 药点：允许
   - 电池 → 后台高耗电/省电策略：允许后台运行

> 备份不包含系统权限和无障碍开关，第 7、8 步要手动做一次。

每天正常用；下面几项各做一次即可。

## 4. 试用期常见问题

**通知不见了**
1. 设置 → 提醒状态看通知是否为「已开」。
2. 打开 App 一次，通知会自动补发。
3. 检查 i管家里的自启动和后台运行权限。

**锁屏上没有卡片**
1. 设置 → 提醒状态 → 锁屏卡片是否为「已开」。
2. 如果是「已开但服务没连上」：按 Home 回桌面，再打开 App。
3. 检查锁屏显示权限。
4. 遮住前置摄像头或关掉人脸解锁的「跳过锁屏」，否则锁屏一闪而过。

**吃错顺序**
点错了用首页顶部的「撤销」，10 分钟内有效，只退一步。

**想换手机**
旧手机导出备份 → 新手机装同一个 APK → 从备份恢复。

## 5. 反馈方式

记录：日期、时间、当时在做什么、看到的界面、能不能重现。能连电脑的话附上：

```powershell
& "adb" logcat -s MedApp
```

## 6. 以后升级

- 升级必须用同一个 release 证书。证书和密码在本地 `keystore/`，**不要丢，也不要外传**。
- 丢掉证书就只能换包名重装，数据无法直接从旧包升级。
- 新版本用同样证书打包后可直接覆盖安装，数据保留。
