# 吃药提醒 · M0.2 锁屏平行测试说明

> 目标：在 iQOO 11 Turbo（OriginOS，Android 12+）上同时验证两条锁屏路线：
>
> **A. 无障碍锁屏卡片**：锁屏中央显示一张白色卡片，可直接点「已吃」。
> **B. 全屏锁屏页**：用 `setShowWhenLocked` 让一个全屏页面盖在锁屏上。
>
> 两条路线互相独立，分别记录结果。这是测试包，不是最终界面。

## 2. 安装 / 升级

1. 直接覆盖安装 0.1.1，**不用卸载**；数据会保留。
2. 装好后先打开一次 App。
3. 如果系统提示「受限制的设置」或无障碍开关是灰的，见下面「路线 A 第 2 步」。
4. 建议先点「清除测试通知」，再点「发送测试通知」，从第 1 顿·饭前开始。

## 3. 路线 A：无障碍锁屏卡片

### 开启服务

1. 打开 App，点「打开无障碍设置」。
2. 找到 **「锁屏吃药卡片」**，点开并开启。
   - 如果找不到：`设置 → 快捷与辅助 → 无障碍 → 已下载的服务 / 已安装的服务`。不同 OriginOS 版本路径略有差异。
   - 如果开关是灰色，或提示「受限制的设置」：  
     `设置 → 应用 → 吃药提醒 → 右上角「⋮」→ 允许受限制的设置`，然后再回到无障碍里开启。
   - 如果 i管家有「锁屏显示」权限，也给「吃药提醒」打开：  
     `i管家 → 应用管理 → 权限管理 → 锁屏显示 → 吃药提醒 → 允许`。
3. 回到 App，看「路线 A」状态：
   - **已开启，服务已连接**：可以继续。
   - **已开启，但服务未连接**：按 Home 回桌面，再打开 App；或把服务关掉再开一次。
   - **未开启**：回到第 2 步。

### 测试

| # | 操作 | 预期 |
|---|---|---|
| 1 | 点「发送测试通知」 | 通知栏出现第 1 顿·饭前 |
| 2 | 按电源键锁屏，等 1–2 秒 | 锁屏中央出现白色卡片：`今天第 1 顿 · 饭前` / `吃饭前吃：测试药 1 片` / 绿色「已吃」 |
| 3 | 在卡片上点「已吃」 | 卡片原地变成：`第 1 顿 · 饭后` / `吃完饭后吃：测试药 1 片` /「吃完后确认」 |
| 4 | 再点「吃完后确认」 | 卡片变成：`测试完成` /「关闭卡片」 |
| 5 | 解锁 | 卡片消失 |

注意事项：

- 测试时先**遮住前置摄像头**，或关闭人脸解锁的「跳过锁屏」，否则锁屏一闪而过，看不到卡片。
- 如果卡片出现但按钮点不动，记录「卡片出现、按钮不可点」；这仍然是有价值的结果。
- 如果卡片不出现，先看 App 里的状态是否「已连接」，再试一次锁屏/亮屏；检查自启动、后台高耗电、电池优化。
- 测试完可以到无障碍设置里把「锁屏吃药卡片」关掉。

## 4. 路线 B：全屏锁屏页

| # | 操作 | 预期 |
|---|---|---|
| 1 | 先点「清除测试通知」，再点「发送测试通知」 | 确保停在第 1 顿·饭前 |
| 2 | 点「显示全屏锁屏页」 | 立即出现全屏页：深色背景 + 白色卡片 |
| 3 | 按电源键锁屏 | 全屏页仍然显示，不被锁屏盖住 |
| 4 | 点「已吃」 | 变成第 1 顿·饭后；再点变成完成 |
| 5 | 点「关闭」 | 退出全屏页，回到 App 或桌面 |

注意事项：

- 全屏页存在期间，路线 A 的卡片会**自动暂停**，避免两条路线互相遮挡；关闭全屏页后恢复。
- 如果全屏页被锁屏盖住，记录「被盖住」；这就是路线 B 的结论。
- 如果全屏页打开后回不到 App，按 Home 键或从最近任务切回 App，再点「关闭」。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 无障碍列表里找不到「锁屏吃药卡片」 | 路径可能是「已下载的服务」；确认 App 已安装并打开过一次 |
| 开关灰色 / 提示受限制 | 设置 → 应用 → 吃药提醒 → 右上角「⋮」→ 允许受限制的设置 |
| 状态「已开启，但服务未连接」 | 按 Home 回桌面，再打开 App；或关掉服务再开 |
| 卡片不出现 | 看状态是否已连接；锁屏/亮屏再来一次；检查自启动、后台高耗电、电池优化 |
| 卡片不出现，但服务已连接 | 检查 i管家 → 应用管理 → 权限管理 → 锁屏显示 → 吃药提醒 → 允许；再锁屏试 |
| 卡片出现但按钮点不动 | 记录结果；可能是 OriginOS 拦截了锁屏上的触摸 |
| 全屏页被锁屏盖住 | 记录结果；说明 `setShowWhenLocked` 被 ROM 拦截 |
| 锁屏一闪而过 | 遮住前置摄像头，或关闭人脸解锁的「跳过锁屏」 |
| 重启后卡片不出现 | 检查无障碍服务是否还在；检查自启动、后台高耗电 |

## 9. 已知限制

- 这是 M0.2 测试包，不是最终的长辈界面。
- 无障碍服务只用于画锁屏卡片，`canRetrieveWindowContent=false`，不读取屏幕内容；测试完可以关闭。
- 锁屏卡片和全屏页的「已吃」按钮**不需要解锁就能点**，这是为了方便长辈；如果担心误触或他人误点，正式版可以加二次确认、长按或指纹。
- 全屏页是测试路线，正式版是否采用要看这次结果。
- 无 `INTERNET` 权限，完全离线。
- Debug 签名只用于测试；正式版换 release keystore 时需要卸载重装一次。
- 如果两条路线都被 OriginOS 拦截，剩下的是 vivo 本地通知渠道备案或通知栏-only，届时再决定。
