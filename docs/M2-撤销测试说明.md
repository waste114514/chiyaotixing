# 药点 · M2 撤销测试说明

> 目标：验证 0.3.0-m2 的「撤销最近一次确认」。
>
> M1 已通过；本版只加撤销，不改原有饭点流程。可以覆盖安装，数据保留。

## 1. APK 信息

| 项 | 值 |
|---|---|
| 文件 | `dist/药点-m2-debug.apk` |
| 包名 | `com.family.yaodian` |
| 版本 | `0.3.0-m2`（versionCode 6） |
| 签名 | Android Debug，可直接覆盖 0.2.1 |
| 网络权限 | 无 `INTERNET` |

## 2. 撤销入口

确认任意一项后，首页顶部出现一条绿色提示：

> 刚刚记下了「第 1 顿 · 饭前」，10 分钟内可以撤销。　[撤销]

- 点「撤销」：回到刚才那一项，已确认的药恢复成操作前的状态。
- 超过 10 分钟：提示消失；强行点会提示「超过 10 分钟，不能撤销了」。
- 只保留最近一次操作；连续确认两次，只能撤销第二次。
- 撤销对以下操作都有效：
  - 单种药确认
  - 「全部已吃 / 吃完后确认」
  - 「这一顿不吃了」

## 3. 测试步骤

### 3.1 单种药撤销

1. 当前阶段有 2 种药。
2. 点第一种药 → 变绿。
3. 点顶部「撤销」。
4. 预期：第一种药恢复未确认，阶段不变。

### 3.2 全部确认后撤销

1. 点「全部已吃」→ 进入下一阶段。
2. 点顶部「撤销」。
3. 预期：回到上一阶段，药品恢复成确认前的状态（如果之前单独确认过一种，那一种仍保持绿色）。

### 3.3 跳过撤销

1. 点「这一顿不吃了」→ 确认 → 进入下一阶段。
2. 点「撤销」。
3. 预期：回到被跳过的那一项，状态恢复为「现在吃」，不记为已跳过。

### 3.4 撤销最后一项

1. 完成当天最后一项 → 显示「今天的药都吃完了」。
2. 点顶部「撤销」。
3. 预期：回到最后一项，通知和锁屏卡片重新出现。

### 3.5 超时

1. 确认一项后，等 10 分钟以上再打开 App。
2. 预期：撤销提示消失，不能撤销。

### 3.6 通知按钮也能撤销

1. 在通知栏点「全部已吃」。
2. 打开 App，首页顶部应有撤销提示。
3. 点「撤销」→ 回到上一项。

## 4. 记录

撤销会写一条 `undo` 事件到 `events-YYYY-MM.jsonl`；当天历史以最终状态为准，不会把已撤销的确认算进去。

## 5. 已知限制

- 只能撤销最近一次，且限 10 分钟。
- 撤销入口只在 App 首页；锁屏卡片和通知上没有撤销按钮。
- 撤销后不会恢复已经划掉的通知计数（会重新发一条当前阶段通知）。
- 跨天后不能撤销前一天的操作。

## 6. 反馈

1. 撤销提示是否出现、是否好点。
2. 三种操作（单药 / 全部 / 跳过）撤销后状态是否正确。
3. 撤销最后一项后，通知和锁屏卡片是否恢复。
4. 10 分钟后提示是否消失。
5. 其它异常截图或 `adb logcat -s MedApp`。
