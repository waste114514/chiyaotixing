# 吃药提醒 · M5b 设置与导航测试说明

> 目标：验证 1.2.0-m5b 的导航改动：设置改齿轮入口、长辈版隐藏记录/药品标签、二级页收束。
>
> 本版是结构改动；长辈版的高对比配色和大字默认值在下一步（M5c）。

## 2. 正常版导航

| # | 操作 | 预期 |
|---|---|---|
| 1 | 看首页顶部 | 标题右侧出现齿轮图标；底部只有 今天 / 记录 / 药品 三个标签 |
| 2 | 点齿轮 | 进入「设置」页；标题变「设置」，左上角出现返回箭头，底部标签消失 |
| 3 | 点返回箭头 | 回到进入设置前所在的页面 |
| 4 | 设置 → 提醒状态 | 进入二级页：通知、锁屏卡片状态，加测试按钮 |
| 5 | 设置 → 调试 | 进入二级页：导出备份、从备份恢复、重新开始今天、全屏大字卡片 |
| 6 | 设置 → 关于 | 显示版本号、离线说明、开源地址占位 |
| 7 | 二级页按返回键 / 点返回箭头 | 回到设置主页面，再返回回到标签页 |
| 8 | 标签页按返回键 | 仍是「再按一次退出」逻辑 |

## 3. 设置页面结构（正常版）

从上到下：

1. **待处理**（只在有问题时显示）：通知没开 / 锁屏卡片没开 / 没连上；处理好后自动消失
2. **界面模式**：正常版 / 长辈版
3. **常用**：字号（标准/大/特大）、一天几顿（2/3/4）
4. **提醒状态**（进入二级页）
5. **药品照片**：关闭 / 列表 / 列表 + 首页
6. **调试**、**关于**（进入二级页）

> 长辈版时，第 4 项下面会多出「药品管理」「记录」两个入口。

## 4. 长辈版导航

| # | 操作 | 预期 |
|---|---|---|
| 1 | 设置 → 界面模式 → 长辈版 | 提示已切换；返回后底部只剩「今天」一个标签 |
| 2 | 顶部齿轮 | 齿轮下方出现「设置」两个字 |
| 3 | 设置页 | 出现「药品管理」「记录」两个入口 |
| 4 | 点「药品管理」 | 进入药品页，左上角返回箭头可回设置 |
| 5 | 在药品页加一条药或改一条 | 保存后回到药品页（不是跳到首页） |
| 6 | 点「记录」 | 进入记录页，返回可回设置 |
| 7 | 切回正常版 | 底部恢复三个标签，「药品管理/记录」入口消失 |

## 5. 药品照片设置

- 现在只验证「设置项能选中并保留」：关闭 / 列表 / 列表 + 首页。
- 实际在药品列表或首页显示照片要等照片功能上线（M5c）；这一版选「列表」也不会出现照片。

## 6. 注意事项

- 长辈版这一版只改结构（隐藏标签、入口收束、齿轮带字），**还没有换高对比配色**，视觉和正常版一致。
- 模式设置保存在 `plan.json`（`uiMode`），照片设置在 `photoMode`，都随备份导出。
- 数据、提醒逻辑未改动。

## 7. 反馈

1. 齿轮入口是否好找、好点；返回箭头是否顺手。
2. 四个标签变三个后，家里长辈会不会找不到记录/药品。
3. 二级页层级是否符合预期；有没有需要合并或拆分的。
4. 长辈版下「药品管理/记录」入口是否清楚。
5. 异常截图或 `adb logcat -s MedApp`。
