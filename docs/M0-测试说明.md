# 吃药提醒 · M0.1 真机测试说明

> **0.1.2 锁屏平行测试请见 `docs/M0.2-平行测试说明.md`；本文件保留 0.1.1 通知链路测试。**

> 目标：验证 iQOO 11 Turbo（OriginOS，Android 12+）上的「常驻通知 + 确认推进 + 重启恢复 + 锁屏可见」。
> 这不是最终界面，只是 M0 技术验证包。
>
> **0.1.1 重点修复**
> - 通知状态改存 device-protected storage，重启后不打开 App 也能恢复。
> - 增加 `LOCKED_BOOT_COMPLETED` / `USER_UNLOCKED` 接收器，开机未解锁也能重发。
> - 新增「锁屏诊断」：分别发常驻静默、非常驻静默、常驻有声三种通知，判断是锁屏设置、静默限制还是常驻限制。
> - 去掉通知上的 `setSilent(true)`，静默改由通知渠道控制。
> - 新增「打开应用通知设置 / 打开通知渠道设置」按钮。

## 2. 安装 / 升级

### 方式 A：USB 拷贝（推荐）

1. 用 USB 线把手机连到电脑，选择「文件传输」。
2. 把 `吃药提醒-m0-debug.apk` 复制到手机的 `Download` 目录。
3. 在手机上打开「文件管理 → Download」，点 APK 安装。
4. 如果之前装过 0.1.0，直接覆盖安装即可；签名相同，数据会保留。
5. 装好后**先打开一次 App**，让它把旧测试状态迁移到新的存储位置。

### 方式 B：adb 安装

```powershell
& "adb" devices
& "adb" install -r "dist/吃药提醒-m0-debug.apk"
```

### 装好后建议先清一次旧测试

打开 App，点「清除测试通知」，再点「发送测试通知」，从第 1 顿重新开始，避免旧状态干扰。

## 3. 首次打开与权限

1. 打开「吃药提醒」。
2. 系统询问通知权限时点「允许」。
3. 页面会显示「通知渠道状态」：
   - 渠道：`meal_ongoing_v2`
   - 重要性：高
   - 锁屏：公开
4. 如果显示「通知权限未开启」，点「打开应用通知设置」，按下面路径打开。

### iQOO / OriginOS 建议设置

| 项 | 路径（以实际系统为准） |
|---|---|
| 应用通知 | 设置 → 通知与状态栏 → 应用通知管理 → 吃药提醒 → 允许通知 |
| 应用锁屏通知 | 同上 → 锁屏通知 → **显示通知内容**（不要选“不显示”） |
| 渠道锁屏通知 | 同上 → 吃药提醒（常驻 v2） → 锁屏通知 → **显示** |
| 系统锁屏通知 | 设置 → 通知与状态栏 → 锁屏通知 → 显示通知 / 显示内容 |
| 锁屏显示权限 | i管家 → 应用管理 → 权限管理 → 锁屏显示 → 吃药提醒 → 允许（如果有这一项） |
| 自启动 | i管家 → 应用管理 → 权限管理 → 自启动 → 吃药提醒 → 允许 |
| 后台高耗电 | 设置 → 电池 → 后台高耗电 → 吃药提醒 → 允许 |
| 电池优化 | 设置 → 电池 → 电池优化 → 吃药提醒 → 不优化 |
| 最近任务锁定 | 最近任务 → 下拉「吃药提醒」卡片 → 锁定 |

> 设置里可能还会看到旧的 `meal_ongoing` 渠道；那是 0.1.0 的，忽略它，本次只看「吃药提醒（常驻 v2）」。

## 5. 锁屏诊断

这一节专门判断「锁屏不显示」到底是哪种限制。**每次只发一种**，发完锁屏看，再回来发下一种。

| 诊断通知 | 特点 | 锁屏是否出现 | 备注 |
|---|---|---|---|
| 发送常驻静默 | ongoing、静默、渠道 v2 |  |  |
| 发送非常驻静默 | 可划掉、静默、渠道 v2 |  |  |
| 发送常驻有声 | ongoing、会响一声、诊断渠道 |  |  |

结果解释：

- **三种都不出现**：应用级/系统级「锁屏通知」没开，或 iQOO 的锁屏显示权限没给。先点「打开应用通知设置」「打开通知渠道设置」逐项检查。
- **只有「常驻有声」出现**：系统把静默通知从锁屏隐藏了；需要产品上决定是否接受极轻的提示音，或改用前台服务/其他方案。
- **只有「非常驻静默」出现**：系统把常驻通知从锁屏隐藏了；需要考虑非 ongoing 通知 + 重发，或前台服务。
- **三种都出现，但主测试通知不出现**：主通知渠道 `meal_ongoing_v2` 的设置有问题；点「打开通知渠道设置」检查，或卸载重装重置渠道。
- **三种都出现，主测试也出现**：锁屏链路正常，可以进 M1。

诊断完点「清除诊断通知」。

### 如果三种都不出现，按这个顺序排查

0. 先确认你看的是**按电源键亮屏后的锁屏**，不是息屏显示（AOD）。息屏显示默认不显示通知。
1. `设置 → 通知与状态栏 → 锁屏通知` → **显示通知内容**（不是“隐藏内容/不显示”）。
2. `设置 → 通知与状态栏 → 应用通知管理 → 吃药提醒`：
   - 允许通知 → 开
   - 锁屏通知 → **显示**
3. 点进 **吃药提醒（常驻 v2）** → 锁屏通知 → **显示**。
4. 点进 **吃药提醒（锁屏诊断·有声）** → 锁屏通知 → **显示**。
5. `i管家 → 应用管理 → 权限管理 → 锁屏显示 → 吃药提醒` → **允许**（如果有这一项）。
6. `设置 → 桌面、锁屏与壁纸 → 锁屏 → 锁屏样式`：如果是“阅图锁屏”，换成 **系统锁屏 / 经典锁屏**。
7. `设置 → 通知与状态栏 → 锁屏通知`：关闭“智能隐藏 / 智能显示”（如果有）。
8. 改完**重启一次**手机，再锁屏测试。
9. **对照测试**：用微信或短信给自己发一条消息，锁屏看是否显示。
   - 微信也不显示 → 系统级设置/锁屏样式问题，不是 App 的问题。
   - 微信能显示、只有吃药提醒不显示 → App/渠道问题；卸载重装 0.1.1，重新允许通知和锁屏通知后再试。

如果做完这些仍不显示，请把「通知渠道状态」卡片里的文字（渠道 / 重要性 / 锁屏）和微信对照结果发我。

## 7. 已知限制

- 这是 M0 测试页，只验证通知链路，不是最终的长辈界面。
- 测试状态存在 device-protected storage（应用私有、未加密），重启未解锁也能读；不存敏感内容。
- 诊断用的「常驻有声」渠道只用于测试，正式版不会保留。
- Debug 签名只用于测试；正式版会换 release keystore，届时需要卸载重装一次。
- 饭点模式按设计**不响铃**；如果最终确认 OriginOS 锁屏不显示静默通知，需要再决定是否接受极轻提示音或改用前台服务。
- 强行停止 App 后，Android 会移除通知；这是系统限制，只能重新打开 App 恢复。
- 如果 OriginOS 把常驻通知清掉，M0 会暴露这个问题；下一步再评估低优先级前台服务保活。
