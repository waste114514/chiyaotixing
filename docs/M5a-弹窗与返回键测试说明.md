## 2. 统一弹窗

改动范围：跳过这一顿、删除药品、重新开始今天、改餐次数量。

预期样式：

- 白色圆角卡片，浮在页面中间，背景变暗
- 大标题 + 一句说明 + 两个大按钮（上：确认，下：取消）
- 危险操作（删除、重新开始）确认按钮是红色描边
- 打开时焦点默认在「取消」；外接键盘按 Esc 等于取消
- 弹窗里不显示药名以外的多余信息

| # | 操作 | 预期 |
|---|---|---|
| 1 | 首页点「这一顿不吃了」 | 出现统一弹窗；点取消，本阶段不变 |
| 2 | 再点一次，点确认按钮 | 记为已跳过，进入下一项，顶部出现撤销提示 |
| 3 | 药品 → 点一条药 → 删除这条药 | 弹窗标题带药名「删除「阿司匹林」？」，确认按钮红色 |
| 4 | 取消删除 | 药还在，列表不变 |
| 5 | 设置 → 重新开始今天 | 红色确认；取消则今天记录不变 |
| 6 | 设置 → 一天 2 顿（有药占用时） | 统一弹窗；确认后如果被占用会提示哪条药 |

## 3. 返回键

| # | 场景 | 预期 |
|---|---|---|
| 1 | 首页/记录/药品/设置，按一次返回键 | 底部提示「再按一次退出」，不退出 |
| 2 | 2 秒内再按一次 | 退出 App |
| 3 | 隔 3 秒再按 | 只再提示一次，不退出 |
| 4 | 添加/编辑药品弹层打开时按返回键 | 关闭弹层，回到上一页，不退出 |
| 5 | 统一弹窗打开时按返回键 | 关闭弹窗，不退出 |
| 6 | 弹层关闭后再按返回键 | 恢复「再按一次退出」逻辑 |

## 4. 注意事项

- 弹窗用系统原生 `<dialog>`；极老的 WebView 不支持时自动退回系统弹窗（正常机型不会遇到）。
- Android 16 的预测性返回已声明（`enableOnBackInvokedCallback=true`），Android 12–15 行为与上表一致。
- 底部标签切换仍然不写历史：在各标签页按返回键都是退出逻辑，不会在标签之间跳。
- 本次没改任何提醒、通知、锁屏逻辑，风险面小；升级后数据不会丢。
