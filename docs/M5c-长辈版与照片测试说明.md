## 2. 长辈版视觉

设置 → 界面模式 → 长辈版，预期：

- 页面变白底、近黑字，卡片边框变粗（3px），去掉阴影和渐变
- 主按钮更高（76px 起），底部标签按钮 68px 起
- 不确定/重要信息不再只靠颜色：勾选符号和文字同时在
- **字号自动升到「特大」**（32px 基准）；如果之前已经是更大档位则保持。之后仍可手动改字号
- 底部只剩「今天」，齿轮带「设置」二字

| # | 操作 | 预期 |
|---|---|---|
| 1 | 切到长辈版 | 上面几项全部生效 |
| 2 | 首页看当前阶段 | 标题、药名、按钮都明显更大更清楚 |
| 3 | 点大按钮确认 | 正常推进；撤销提示仍在 |
| 4 | 设置 → 字号 | 可改回标准/大，改完即生效 |
| 5 | 切回正常版 | 恢复原配色与三标签；字号保留你最后的选择 |

## 3. 药品照片

### 3.1 先选显示方式

设置 → 药品照片：关闭 / 列表 / 列表 + 首页。

- 关闭：任何地方都不显示照片
- 列表：只在药品列表里显示小图
- 列表 + 首页：列表和首页当前阶段都显示

### 3.2 给一条药加照片

1. 设置 → 药品管理（长辈版）或底部「药品」（正常版）
2. 点开一条药 → 「药品照片（可选）」→ 选择照片
3. 系统照片选择器打开 → 选一张
4. 预期：提示「照片已保存」，弹层里出现预览图，下面有「更换 / 删除」

| # | 操作 | 预期 |
|---|---|---|
| 1 | 选择照片 | 预览出现；按设置的方式在列表/首页出现小图 |
| 2 | 点「更换」 | 重新选一张，旧图被替换 |
| 3 | 点「删除」 | 预览消失；列表和首页不再显示 |
| 4 | 没有照片的药 | 完全按文字显示，不出现占位图、不出现灰框 |
| 5 | 新建一条药 | 编辑页提示「先保存这条药，再回来添加照片」（新药还没有 ID） |

### 3.3 说明

- 照片保存在 App 私有目录，压缩到最长边 720px 的 JPEG；不需要相机权限，只用系统照片选择器。
- 照片**不包含在 JSON 备份里**；恢复备份会清掉本机旧照片（因为备份里的药没有照片引用），文字数据不受影响。
- 锁屏卡片暂不显示照片（后续可选）。
- Android 9 以下设备照片方向可能不正（老机型极少）。

## 4. 备份字段变化

- 备份现在会保留「界面模式」和「照片显示方式」两项设置。
- 恢复后：药品、餐次、历史、模式、照片显示方式都回到备份时的状态。

## 5. 回归检查（抽查即可）

1. 首页确认、逐种确认、撤销。
2. 通知按钮推进、划掉重发。
3. 锁屏卡片出现与确认。
4. 统计：导出备份 → 恢复备份。
5. 返回键：弹层先关、一级页双击退出。

## 6. 反馈

1. 长辈版配色在大太阳/室内光下是否清楚，有没有太刺眼。
2. 长辈版默认「特大」后，首页一屏能不能看到「药名 + 大按钮」。
3. 照片显示在列表/首页的大小是否合适。
4. 选照片、换照片、删照片是否顺畅。
5. 异常截图或 `adb logcat -s MedApp`。
